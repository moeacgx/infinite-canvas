## 说明

- 画布项目和“我的素材”默认保存在浏览器本地；如需跨设备合并，可在配置中启用 WebDAV 同步。
- 本地直连模式下，AI API Key 保存在浏览器本地。前端优先直连第三方接口；登录用户遇到 CORS、OPTIONS、证书或网络问题时，可自动回退到受限的服务端转发。
